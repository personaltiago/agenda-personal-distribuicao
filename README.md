# agenda-personal-distribuicao
Distribuição oficial do aplicativo Agenda Personal

Este repositório contém **somente** as páginas públicas de instalação e de cadastro do aluno e os APKs publicados em **Releases**. Ele não contém código-fonte do aplicativo, chaves, dados de alunos nem arquivos de desenvolvimento.

| Página | Endereço |
|---|---|
| Instalação (Android e iPhone) | https://personaltiago.github.io/agenda-personal-distribuicao/instalar.html |
| Cadastro do aluno | https://personaltiago.github.io/agenda-personal-distribuicao/cadastro-aluno.html |

O APK Android é publicado em Releases com o nome `AgendaPersonal-Android.apk`, na tag `android-<versão>-conteudo-<conteúdo>-<execução>`, assinado com a chave oficial do Agenda Personal.
